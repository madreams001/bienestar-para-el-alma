# Bienestar para el Alma - Multiespacio

Sitio estatico de 5 paginas autocontenidas (HTML + CSS + JS inline).

## Contenido

- `index.html` - Inicio con las 4 propuestas
- `yoga.html` - Yoga
- `ritmos.html` - Ritmos
- `funcional.html` - Funcional
- `pnl.html` - PNL / Coaching
- `img/` - 4 imagenes locales (`yoga.jpg`, `ritmos.jpg`, `funcional.jpg`, `pnl.jpg`)

Todos los enlaces entre paginas e imagenes son relativos. Las unicas URLs absolutas externas son Google Fonts y los enlaces de WhatsApp (`wa.me`), que deben mantenerse.

## Publicar en GitHub Pages

1. Crear un repositorio nuevo en GitHub (por ejemplo `bienestar-alma`).
2. Subir estos archivos a la raiz del repositorio (o a la carpeta `docs/`):
   `index.html`, `yoga.html`, `ritmos.html`, `funcional.html`, `pnl.html` y la carpeta `img/` completa.
3. En GitHub, ir a Settings > Pages.
4. En "Source", elegir la rama (`main`) y la carpeta (`/ (root)` o `/docs` segun donde se subieron los archivos). Guardar.
5. Esperar 1-2 minutos y abrir la URL que muestra GitHub Pages (por ejemplo `https://usuario.github.io/bienestar-alma/`).

No requiere compilacion ni servidor: cualquier archivo `*.html` abre la navegacion completa.
